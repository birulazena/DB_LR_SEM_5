## 1. Описание проекта
Проект представляет собой ядро информационной системы логистической компании. Система обеспечивает управление заказами на грузоперевозки, распределительными складами, автопарком, формирование рейсов водителей и прохождение таможенного контроля.

### Ключевые архитектурные решения:
1. **Безопасность (RBAC):** Разграничение прав доступа построено на концепции "Роли как контейнеры привилегий". Роль агрегирует атомарные разрешения (`permissions`). Проверка прав доступа в Spring Boot осуществляется исключительно по пермишенам.
2. **Мягкое удаление (Soft Delete):** Все основные бизнес-сущности (пользователи, склады, автомобили, заказы, рейсы) поддерживают флаг `is_deleted`. Данные физически не удаляются из таблиц, что гарантирует абсолютную ссылочную целостность истории заказов и журнала аудита.
3. **Журнал событий (Business Event Log):** Все критически важные изменения данных логируются в таблице `audit_logs` с обязательной привязкой к идентификатору пользователя-инициатора (`user_id`).
